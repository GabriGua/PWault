# PWault

**PWault** is a local password manager designed to securely store and manage your passwords using modern security technologies.

All sensitive data is stored locally, giving you full control over your credentials without relying on external servers.

## Main Features

* Local password storage
* Secure password hashing with Argon2
* Credential management
* Password search
* Command-line interface (CLI)
* Graphical user interface (GUI) — currently under development
* Standalone Windows executable
